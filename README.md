 

Простое сетевое приложение на C++, реализующее TCP-сервер и клиент для обмена командами
Структура проекта
network-app/
 server_linux.cpp        
client_windows.cpp     
erver_windows.cpp    





 Создаёт TCP-сервер с использованием POSIX-сокетов.
Принимает подключение клиента.
 Отправляет и принимает структуру `Command`.
 Логирует процесс подключения и обмена данными.

 Windows-клиент 
 Подключается к серверу по адресу.
 Принимает сообщение от сервера и выводит его в консоль.

Windows-сервер 
 Запускает TCP-сервер на порту .
 Принимает клиентское подключение.
 Отправляет тестовое сообщение.
